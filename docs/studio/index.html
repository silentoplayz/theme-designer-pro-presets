Install opens your designer with the theme ready, and you confirm it there. Or drop the downloaded file on the designer, or paste the copied JSON into it. Submitting opens the gallery's submission form on GitHub with your theme filled in. A theme with a Canvas FX script is too long for that, so its JSON is copied for you to paste instead.
